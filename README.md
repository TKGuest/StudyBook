# 🎓 StudyBook — The Educational Social Network

> **Turning scrolling habits into scoring grades.** Built for the **N-HSIC 2026** Innovation Challenge.

---

## 🚀 Project Overview

**StudyBook** is an open-source educational social network that completely flips the script on digital distraction. Instead of fighting the highly engaging mechanics of modern social media platforms, StudyBook wraps Facebook's familiar, intuitive user experience around a productive, triple-sided academic ecosystem. 

Our platform connects **eager learners, student knowledge-sharers, and professional educators** in a single space—fostering peer-to-peer collaboration, resource indexing, and tutor marketplace monetization without the common friction of traditional, boring learning management tools.

---

## 🌟 Core Feature Ecosystem

### 📰 1. The Interactive Newsfeed
* **"What are you studying today?":** A familiar status dashboard allowing users to attach rich text, downloadable PDFs, educational links, and embedded video lectures.
* **Academic Reactions:** Facebook's iconic muscle-memory mapped directly to student emotions: 👍 *Helpful*, ❤️ *Saved My Life*, 💡 *Insightful*, ❓ *Confused*, 😢 *Relatable*, and 😡 *Frustrated*.
* **Subject-Filtering Bars:** Sticky horizontal pill tags (`[Math]`, `[Physics]`, `[Grade 11]`) allowing users to instantly filter out noise and isolate target topics.
* **Save to Library:** A one-click bookmark function that automatically archives documents into categorized digital subject binders.

### 👨‍🏫 2. Pages & Messenger (Tutor Marketplace)
* **Tutor Public Pages:** Official creator profiles optimized for educators to distribute bite-sized tips, build followings, and exhibit a **Review Carousel** of verified student testimonials.
* **The "Book Course" Funnel:** A persistent CTA button on tutor pages that hooks into an automated **Messenger Chatbot**, capturing student data and handling class enrollments instantly.
* **Study Group Chats:** Automated real-time chat rooms tied directly to collaborative study groups for rapid-fire homework help.

### 📺 3. Micro-Video & Engagement (Reels & Live)
* **Educational Reels:** A dedicated vertical video scroll for 60-second micro-learning clips featuring a persistent **"Get Worksheet"** overlay to download source PDFs instantly.
* **Study Stream Live:** Real-time broadcasting tools for mock-exam reviews, complete with **Pin-a-Problem** features for live interactive problem-solving.

### 🎮 4. Academic Gamification
* **Daily Study Streak Rings:** Glowing circular profile avatars that brighten based on daily consistency.
* **Top Answerer Medals:** Automated badges identifying reliable peer mentors in comment threads.

---

## ⚙️ Hyper-Localized Settings
* **Night Owl Mode:** An eye-protecting, instant dual-layout theme for late-night study marathons.
* **Language Matrix Selection:** A multi-select filter ensuring users only interact with posts in their fluent languages.
* **Geographical Curriculum Sync:** Automatically aligns the backend timeline feed to the user's regional national curriculum standards.

## 🛠️ Technical Architecture

This repository contains the full prototype codebase divided into two core layers:
1. **Frontend:** A responsive interface engineered for smooth, native UI rendering.
2. **Backend:** A scalable architecture written completely in **Python**, handling rapid database operations, feed queries, and algorithmic subject curation.
