# 🎓 StudyBook

> **Turning scrolling habits into scoring grades.** Built for the **N-HSIC 2026** Innovation Challenge.

## 🚀 Project Overview
**StudyBook** is an educational social network that uses the familiar layout of Facebook to turn casual scrolling habits into productive studying habits. It connects students, resource-sharers, and professional tutors in a single ecosystem designed to improve the quality of student life.

## 📰 Core Features

* **The Newsfeed:** A scrollable timeline where users can post text, upload PDFs, share website links, or embed YouTube video lectures.
* **Subject Filters:** Horizontal tabs (like `[Math]`, `[Physics]`, `[Grade 11]`) to instantly filter the feed and remove distractions.
* **Academic Reactions:** Facebook's 6 standard reaction slots mapped to student emotions (👍 *Helpful*, ❤️ *Saved My Life*, 💡 *Insightful*, ❓ *Confused*, 😢 *Relatable*, 😡 *Frustrated*).
* **Save to Library:** A one-click bookmark button that saves documents into categorized digital subject folders.
* **Tutor Pages & Booking:** Dedicated profiles for teachers featuring student review carousels and an automated Messenger chatbot for quick course registration.
* **Educational Reels & Live Streams:** Vertical 60-second learning videos with a "Get Worksheet" download button, alongside live streams with a "Pin-a-Problem" feature for real-time tutoring.
* **Gamification:** Glowing study-streak rings around profile pictures and "Top Answerer" badges next to helpful users' names.
* **Settings Menu:** Built-in dark/light mode toggle, multi-language post selection, and geographical curriculum targeting.

## 🛠️ Tech Stack
* **Frontend:** Responsive user interface designed for intuitive navigation.
* **Backend:** Scalable server architecture coded entirely in **Python** to handle real-time feeds, search queries, and database actions.
